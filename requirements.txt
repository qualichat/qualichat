# `pip install -r requirements.txt`. It bundles every dependency

# the two spaCy language models (downloaded from the spacy-models
# GitHub releases, since Streamlit Cloud cannot run setup scripts).

# For local development prefer `pip install -e ".[dev]"` driven by
# pyproject.toml; this file exists primarily so Streamlit Cloud can
# build the web UI deploy.
#
# numpy version note
# ------------------
# We do NOT pin numpy. Streamlit Cloud's resolver picks numpy 2.x by
# default and modern wheels for chat-miner/polars/pandas/spaCy 3.8+
# are compiled against the numpy 2.x ABI. A previous attempt to pin
# numpy<2 surfaced the inverse error (`Expected 96 from C header, got
# 88 from PyObject`) because the C extensions were compiled against
# 2.x but the runtime had 1.x. Spacy 3.8 added official numpy 2.x
# support, which is why we bump from 3.7→3.8 below.
